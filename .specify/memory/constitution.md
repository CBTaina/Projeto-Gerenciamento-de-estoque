# Constituição do Projeto

## Princípios obrigatórios

### 1. Interface moderna e limpa

As interfaces devem priorizar clareza, hierarquia visual e conteúdo fácil de
entender. Evite ruído visual e elementos decorativos que não ajudem a tarefa do
usuário.

### 2. Responsividade mobile-first

Toda interface deve ser projetada primeiro para telas pequenas e adaptada para
os demais tamanhos. O conteúdo e as ações devem permanecer utilizáveis em
celulares, tablets e desktops, sem rolagem horizontal indevida.

### 3. Paleta de cores consistente

Use uma paleta compartilhada e tokens semânticos para cores e estados. Novas
cores não devem ser introduzidas isoladamente quando um token existente puder
ser reutilizado.

### 4. Acessibilidade por padrão

Use HTML semântico, rótulos associados aos controles, nomes acessíveis,
navegação por teclado e foco visível. Garanta contraste conforme WCAG 2.2 nível
AA: pelo menos 4,5:1 para texto comum, 3:1 para texto grande e 3:1 para
componentes e elementos gráficos relevantes.

### 5. Componentes modulares

Organize a interface em componentes coesos, com responsabilidades claras.
Reutilize componentes e lógica compartilhada quando isso reduzir duplicação sem
criar abstrações desnecessárias.

## Conformidade

Toda nova funcionalidade e alteração de interface deve respeitar estes
princípios. Revisões e testes devem verificar responsividade, acessibilidade e
consistência visual nas partes afetadas. Em caso de conflito, a implementação
deve ser ajustada antes de ser considerada concluída.
